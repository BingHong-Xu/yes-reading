# 永貞國小數位閱讀成果網（蘆映書院｜2024–2026 閱讀教學典藏）

本專案依 **L1 至 L6 教育機構官網六層資訊架構** 與 **WCAG 2.1 Level AA** 無障礙設計理念建置，並完整串聯 `E:\2024-2026閱讀教學` 八大分類典藏統計（6,745 份去重實證檔案）、38 個次資料夾與真實學校書單／影像。

## 快速開啟方式
1. **直接雙擊開啟**：直接用 Chrome 或 Edge 雙擊 [index.html](index.html) 即可離線完整運作（所有資料皆透過同步 `js/archive-data.js` 載入，不受 `file:///` 跨網域限制）。
2. **本機伺服器預覽**：雙擊 [啟動本機預覽.bat](啟動本機預覽.bat)，於 `http://127.0.0.1:8080/index.html` 開啟預覽。

## 專案結構
- `index.html`：語意化 HTML5（`<header>`、`<nav>`、`<main>`、`<footer>`、無障礙快速跳轉、L1–L6 區塊與 9 種互動彈窗）。
- `css/styles.css`：深藍 `#1E3A8A`、暖陽金 `#D97706`、淺灰白 `#F8FAFC` 視覺系統與桌面／行動版 RWD（含 767px 手風琴收合與漢堡選單）。
- `js/archive-data.js`：自 `E:\2024-2026閱讀教學` 彙整產出之 8 大類目統計、38 個次資料夾代表檔名與 45 本分齡活動書單。
- `js/app.js`：原生 JavaScript（輪播暫停／播放、跑馬燈控制、全站關鍵字搜尋、OPAC 書目查詢、聊書投稿與志工排班持久化、L4 頁籤、L5 分齡任務切換、L6 手風琴與雙據點平面圖彈窗）。
- `assets/images/`：24 張經 EXIF 方向校正與網頁化最佳化之永貞閱讀現場實照、工程平面圖與榮譽獎狀。
